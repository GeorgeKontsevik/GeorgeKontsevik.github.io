# Project records

One Markdown file is one project. Retain front matter fields used by the archive card: `title`, `collection: portfolio`, `permalink`, `excerpt`, `image`, and `image_alt`.

Use `category: unfinished` only for a genuine ongoing project. It remains public and is grouped by `_pages/portfolio.md`. Put detailed project copy in the Markdown body and use `/images/projects/...` for project images.
