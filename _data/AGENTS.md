# Data files

- `authors.yml`: biography and author-profile data.
- `navigation.yml`: visible masthead navigation and page order.
- `section_cards.yml`: ordered cards used by Teaching and Talks. Keep YAML indentation consistent.
- `ui-text.yml`: theme wording; change only when a shared label must change site-wide.

For Talks, set a four-digit `year`; `_pages/talks.md` uses it for newest-first grouping. Add `image`, `image_alt`, `title`, and concise English copy to new cards.
